Hover, focus or click an underlined name.

How it works

Hover, focus or click an underlined identifier to see the type the compiler would infer, shown in a popover under that token. Arrow keys move between identifiers and Escape closes the popover, so a presenter can answer “what is this?” without leaving the slide. Reset clears it.
