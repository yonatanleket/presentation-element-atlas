How it works

A vector animation plays the kind of short icon sequence a Lottie file would carry: the ring draws, the check strokes in with a slight pop, then dots burst outward. Here it is rebuilt with SVG strokes and CSS, so it stays sharp at any size and weighs almost nothing.
